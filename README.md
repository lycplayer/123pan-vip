## ✨ 功能一览

| 能力 | 说明 |
|---|---|
| **接管官方客户端** | 用 hosts 把 123 域名指向本机 + 443 透明劫持，让**不认系统代理**的桌面客户端也走液态玻璃 |
| **本地抓包** | 实时记录全部请求（方法 / URL / 状态码 / 类型 / 大小 / 耗时），可看请求头、请求体、响应头、响应体 |
| **实时改写** | `start`（拦截）/ `header`（改请求头）/ `end`（改响应体）三阶段按规则改写 |
| **会员解锁** | 改写会员接口响应：VIP / SVIP / 永久会员、去广告、自定义昵称头像等级；带「客户端接口自动适配」兜底规则 |
| **下载增强** | 下载接口伪装安卓端、拦截流量超限支付窗口、还原真实直链 |
| **隐私拦截** | 屏蔽埋点上报（web_logs / metrics / sentry）与广告域名 |
| **自定义规则** | URL 包含 / 正则 / 域名匹配 + 改 JSON 字段、改请求头、文本替换、拦截、Python 脚本 |
| **秒传工坊** | 秒传链接生成（导出）与保存（导入），登录态从流量自动提取 |
| **批量转存** | 夸克 / 天翼 / 光鸭网盘的文件（个人或分享链接）搬到 123 |

## 🚀 运行方式

- **源码运行**：双击 `启动液态玻璃.bat`，或命令行 `python app.py`。
- **打包版本**：运行 `dist/LiquidGlass/LiquidGlass.exe`（PyInstaller 打包，自带 `ui/` 与本地根证书，无需 Python 环境）。

运行依赖（仅源码运行需要）：`pywebview`、`cryptography`、`requests`。

## 🪜 三步接管官方客户端（主页就是它）

1. **安装根证书** — 主页点「安装根证书」，UAC 选「是」。客户端会校验 HTTPS，不装会连不上。
2. **开启接管** — 拨主页大开关。软件会解析 123 域名的真实 IP、监听本机 443、把域名写进 hosts 指向 127.0.0.1。
3. **启动客户端** — 点「启动客户端」（自动查找，找不到可手动指定 exe），正常登录即可，抓包页会实时出现请求。

关闭开关或退出软件会自动还原 hosts。

> 若提示 443 被占用：hosts 只能指向 443，需要关掉占用程序（IIS / nginx / VMware / Skype 等），点「检查 443 端口」可确认。
> 浏览器用户：到「设置」里打开「接管系统代理」，或用主页的浏览器入口。

## 🛠 规则怎么写

一条规则 = **匹配**（哪个请求）+ **阶段**（何时生效）+ **动作**（做什么）。

- 阶段：`start` 直接拦下不发网络请求；`header` 改请求头；`end` 改响应体。
- 匹配：`URL 包含` / `正则` / `路径包含` / `域名包含` / `URL 前缀`。
- 动作：
  - `修改响应 JSON 字段`：每行 `data.Vip=true`，支持点路径。
  - `设置请求头`：每行 `platform=android`。
  - `文本替换`：支持正则。
  - `直接拦截`：自定义返回的 JSON。
  - `Python 脚本`：变量 `res`（响应对象）、`headers`、`url`、`cfg`，结果赋值给 `out`。

编辑器里有「用样例响应试跑」，可以先验证再保存。

## 🐞 排查

| 现象 | 处理 |
|---|---|
| 内置浏览器打不开 / 崩 | 点 **「Edge 独立窗口」**（独立配置启动，代理参数一定生效，崩了也不影响主程序）；内置窗口失效时会自动降级到它 |
| 页面白屏 / 资源加载不全 | 看仪表盘大开关是否为绿色；未运行说明端口被占用（上一进程未退出），换个端口或重开 |
| HTTPS 站点报证书错误 | 点「安装根证书」并在 UAC 点「是」，然后重启浏览器 |
| 抓包面板没数据 | 确认是用内置浏览器 / Edge 独立窗口打开的，或已「接管系统代理」 |
| 想看程序内部日志 | `data/logs/gui.log`；抓包导出在 `data/traffic_*.json` |

## ⚠️ 已知限制

- 仅支持 HTTP/1.1；HTTP/2 会在代理处降级为 1.1（功能不受影响），WebSocket 走盲转发不解析。
- 抓包记录默认保留最近 3000 条、单条响应体 256KB（可在设置里改）。
- 若目标 App 使用证书固定（Certificate Pinning），MITM 拦截会失败 —— 浏览器不受此限制。
- 秒传功能需要登录态：先在内置浏览器登录 123 云盘，软件会自动从流量里提取 Authorization。
- 会员伪装只影响本机的网页显示，不改变服务端真实权益（与原始脚本一致）。
